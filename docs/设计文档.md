
# 分层并行聚类的多模型调试联邦学习系统：

## 设计思路

核心思路：

数据：用户进程－窗口－行为的拼接字符串，例如：msedge.exe－DeepSeek－key_press－ｕ
分层聚类：每个客户端先在本地对自己的行为数据进行嵌入和分层次聚类，（当前实现里用的聚类算法为kmeans）

*     上层聚类的类别较少，主要提取用户的行为模式，例如可能的行为有：学习，刷视频，编程之类的
*     下层聚类的类别较多，视每个进程有且只有２类操作（鼠标点击与键盘输入），令动作类别数为进程数＊２

二次聚类：由于每个客户端的聚类结果都不一样，我们需要进行类型的对齐，客户端将数据上传到服务器后，服务器将收集到的上层与下层聚类各ｎｘｍ个聚类中心重新聚类为ｎ个聚类中心，其中m为客户端数量，n为聚类中心数量
由此得到一批全局行为原型N1与N2（N1为上层聚类中心的集合，N2为下层聚类中心的集合）。每个N1的原型对应一个专门的预测模型，在联邦学习框架下进行个性化训练，预测的对象为N2分类。实际使用时，通过一个轻量级决策模型判断用户当前状态，并动态调用对应的个性化模型进行预测。即通过判断用户当前状态在该状态模型下进行行为预测

**有哪些优势**

* 隐私保护好：原始数据始终留在本地，上传的只有聚类中心向量和模型更新量。
* 通信效率高：不传原始数据，只传压缩后的特征与模型增量，节省带宽。
* 适应性强：分层聚类能缓解不同用户之间的数据差异，提取更具代表性的行为模式。
* 灵活度高：系统不依赖具体的聚类算法与模型，可以更换不同的算法与模型进行验证


## 具体流程

1. **报到与准备** ：客户端连接服务器，校验并下载统一的嵌入模型，在本地对行为数据做双路处理与聚类，生成状态和动作两类聚类中心上传至服务器。
2. **全局原型生成** ：服务器收集所有客户端的聚类中心，分别进行状态与动作的联邦聚类，得到全局原型，并初始化对应数量的预测模型和决策模型。
3. **本地训练准备** ：客户端根据全局原型对本地数据重新标注，并按状态类别准备好对应的个性化模型副本。
4. **联邦训练循环** ：服务器每轮选择部分客户端，下发最新全局模型；客户端并行训练各状态对应的预测模型以及决策模型，加密上传模型更新；服务器安全聚合更新，迭代多轮直至收敛。
5. **在线预测** ：实时捕获用户行为序列，先通过决策模型判断下一时刻的状态类别，再调度对应的个性化预测模型输出具体操作概率，完成行为预测。

## 可改进点

* 当前的kmeans聚类算法需要人为或通过肘部法则计算类别数量，可以采用灵活性更高的算法动态的生成类别数量
* 当前使用的lstm模型为标准模型，可以根据用户行为预测任务进行对应的调参
* 可以可视化分析用户的行为分布来进行进一步的优化
* 用户行为的向量嵌入目前使用的all-MiniLM-L6-v2，384维，可以考虑使用更强大的嵌入模型
