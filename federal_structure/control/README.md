# 联邦学习系统控制器使用说明

联邦学习系统控制器（newcontrol.py）是联邦学习系统的统一控制入口，支持服务器/客户端的启停、训练启动、状态监控等功能。

## 功能概览

控制器提供以下核心功能：

1. **启动服务器**：启动联邦学习服务器容器
2. **启动客户端**：启动联邦学习客户端容器
3. **开始训练**：启动联邦训练流程
4. **查看已连接客户端**：显示已注册的客户端列表
5. **停止服务器**：停止服务器容器
6. **停止单个客户端**：停止指定的客户端容器
7. **停止所有客户端**：停止所有客户端容器
8. **查看服务器状态**：检查服务器运行状态
9. **查看客户端输出**：查看客户端容器日志
10. **退出系统**：退出控制器

## 使用说明

### 启动控制器

```bash
cd federal_structure/control
python newcontrol.py
```

### 1. 启动服务器

选择菜单选项 `1` 启动服务器容器。

**参数配置**：
- 原型数量：输入用于聚类的原型数量（默认4）
- 端口号：服务器监听端口（默认8000）
- 主机地址：服务器绑定地址（默认0.0.0.0）

**注意事项**：
- 确保Docker服务正在运行
- 选择未被占用的端口
- 服务器启动后会等待客户端注册

### 2. 启动客户端

选择菜单选项 `2` 启动客户端容器。

**参数配置**：
- 服务器地址：输入服务器URL（默认 http://server:8000）
- 隐私级别：选择隐私保护级别（low/medium/high，默认medium）
- 数据文件路径：输入数据文件路径（默认 /app/data/activity_log.jsonl）

**数据文件说明**：
- 容器内的 `/app/data` 目录映射到宿主机的 `data` 目录
- 数据文件应为 JSONL 格式
- 推荐使用 `activity_log.jsonl` 文件名

### 3. 开始训练

选择菜单选项 `3` 启动联邦训练流程。

**流程说明**：
- 检查是否有已注册的客户端
- 服务器生成全局原型
- 向客户端分发训练任务
- 收集客户端模型更新
- 执行联邦平均算法

**响应格式**：
- 成功响应：显示参与客户端数量、模型架构等信息
- 失败响应：显示具体错误信息

### 4. 查看已连接客户端

选择菜单选项 `4` 显示已连接到服务器的客户端列表。

### 5. 停止服务器/客户端

- 选择 `5` 停止服务器容器
- 选择 `6` 停止单个客户端容器
- 选择 `7` 停止所有客户端容器

### 6. 查看状态

- 选择 `8` 查看服务器状态
- 选择 `9` 查看客户端日志输出

## 系统架构

### 容器化部署

- 服务器端和客户端均通过Docker容器方式部署
- 使用Docker Compose进行多容器统一管理
- 实现环境隔离和依赖版本一致性

### 非重建性启动策略

所有启动操作遵循"非重建性启动优先"原则：

1. 检查容器状态
2. 若容器已停止，执行 `docker-compose start` 重用原有容器
3. 若容器运行中，提示服务已在运行
4. 若容器不存在，执行 `docker-compose up -d` 创建并启动新容器

## 常见问题

### 服务器启动失败

1. 检查Docker服务是否运行
2. 检查端口是否被占用
3. 检查防火墙设置

### 客户端无法连接服务器

1. 确认服务器已启动并正常运行
2. 检查服务器地址配置是否正确
3. 检查网络连接是否正常

### 训练启动超时

- 训练启动可能需要较长时间（最多120秒）
- 确保有足够数量的客户端已注册
- 检查客户端数据是否符合要求

## 配置管理

### 环境变量

控制器通过环境变量传递配置参数：

- `SERVER_URL`：服务器地址
- `PROTOTYPES`：原型数量
- `PORT`：服务器端口

### 数据路径

- 宿主机 `data` 目录映射到容器内 `/app/data`
- 客户端数据文件应存放在此目录下
- 推荐使用 `activity_log.jsonl` 文件名

## 维护与调试

### 查看日志

```bash
# 查看服务器日志
docker-compose logs server

# 查看客户端日志
docker logs federated-client-<ID>
```

### 停止服务

```bash
# 停止服务器
docker-compose stop server

# 停止所有客户端
docker stop $(docker ps -q -f name=federated-client-)
```
